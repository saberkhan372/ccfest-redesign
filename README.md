# CC Fest single-event wireframe

This is a deliberately neutral gray-box wireframe for a single virtual CC Fest
event page. It establishes content order and approximate space requirements
before visual design or the “10 interpretations of CC” interaction is applied.

## Page structure

1. Event title: “virtual CC Fest on ________, 2026”
2. Keynotes: profile image, name, and short biography
3. Sessions: schedule, presenter image and biography, level, format, and details
4. Registration: placeholder for an Eventbrite embed
5. One minimal history note: the first CC Fest was October 22, 2016

## Content still needed

- confirmed event date and time zone;
- keynote names, headshots, biographies, and links;
- session schedule, presenter information, levels, and requirements;
- Eventbrite event ID or embed code.

The page is plain HTML and CSS with no JavaScript or build step. `.nojekyll`
keeps it ready for GitHub Pages.

## Sources used for the structure
