## Findings

### Latest commit: Copy label can get stuck (P3)

`poster-maker.js:621–622` saves the current button label on each click. Click Copy caption twice within 1.8 seconds: the second click saves `Copied ✓` as its original label. When both timers finish, the button remains `Copied ✓`. The same applies to Copy description. Reproduced by executing the actual handler in Node with a clipboard stub and controlled timers; copying itself succeeds. Keep a stable original label and cancel/restart one reset timer per button. Add a rapid-repeat check.

### Latest commit: sticky-preview checks can measure mid-scroll (P2, test reliability)

`scripts/verify-poster.cjs:197–203` and `233–235` use `scrollTo(0, …)` followed by a fixed 200 ms delay. The site enables smooth scrolling, and GOTCHAS.md already documents this source of unreliable position checks. These checks do not establish that scrolling has reached its destination. Use `scrollTo({top: …, behavior: 'instant'})`, then assert position; also exercise a short landscape viewport and keyboard navigation beneath the pinned preview. This is a source-level finding; a fresh browser reproduction was blocked.

### Earlier schedule commits: clearing a round can remove a workshop (P2)

`register/index.html:119` and `123` use `session.schedule_id == blank` for the pending-workshop fallback. This conflicts with the documented Jekyll 3.10 behavior in GOTCHAS.md: missing/empty fields must be normalized with `default: '' | strip` and compared with `''`. A workshop whose round is cleared no longer matches a scheduled block and can also fail this fallback, disappearing instead of appearing under “Round to be announced.” Normalize both the title and round in both loops. Verify fixtures with a missing key, an empty string and whitespace. Current programme entries all have rounds, so current counts do not exercise this case. Fresh Jekyll reproduction was blocked.

The associated browser assertion uses `:not([data-block])`, although session-card.html always emits `data-block`, including empty values. Count source records against rendered records and explicitly test an empty assignment rather than checking attribute absence.
