# Editable campaign posters — October 5, 2026

## Verified

The campaign file now contains editable counterparts for all 30 static assets in the two requested folders: 16 session/panel spotlights, nine carousel slides, four countdowns and the teaser cover. The Bolder page also retains 14 existing alternate designs. Spotlight frames have 15–24 native text layers each, with separate portrait/artwork images and vector shapes. Carousel frames contain native text and reusable component instances. These are layered designs, not flattened poster PNGs.

“Editable” has limits: the spotlight SESSION/PANEL mastheads are vector outlines rather than a single text field; photos and some animation artwork are raster images. Session titles, presenter names, descriptions, event details and credits are text layers (the SVG import split some paragraphs across individual lines). Animations in the local MP4s are not verified as editable Figma timelines. The full scripting audit found no missing fonts in the existing 39 poster frames. The five new frames use native Anybody/Overpass Mono text, the existing color variables, wordmark/QR/footer components, and a separate image for the original decorative artwork. New text was created successfully; all new frames report no missing fonts and no text outside their poster bounds.

The Figma spotlight overview was visually inspected. It differs from the local stills in title wrapping and decorative artwork placement/cropping. Presence and editable text are verified; exact export parity is not.
